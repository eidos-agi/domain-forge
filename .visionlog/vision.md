# Vision

Naming a company on the open web should not be a tab of registrar search boxes and a gut feeling.

`domain-forge` exists so an agent can take a seed — a brand, a pair of words, an existing domain — and return three honest artifacts in order: alternative names, a score for how much a person will like saying them, and a registry signal for whether they are empty.

The forge refuses to buy. Love is a named rubric, not a model vibe. Availability is RDAP, not a shopping cart. The human still spends the money.
