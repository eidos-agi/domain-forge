# Security Policy

## Reporting a Vulnerability

Report vulnerabilities via GitHub Security Advisories on [eidos-agi/domain-forge](https://github.com/eidos-agi/domain-forge/security/advisories).

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We will acknowledge the report within 48 hours and aim to fix critical issues within 7 days.

## What this tool does not do

domain-forge does not store registrar credentials and does not register domains. A vulnerability that adds a purchase path is in scope — treat it as critical.
